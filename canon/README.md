# Mandala Day — Canon

This folder is the **living canon** for Mandala Day meditation scripts. It is the
authoritative reference for designing and writing investigations (adult and children's)
and producing copy/paste-ready ElevenLabs narration scores.

## Files

- **[CANON.md](CANON.md)** — the philosophy and design principles, organized into the
  seven volumes. The *why* and the *how* of an investigation. Framework v2.2.
- **[NOTATION.md](NOTATION.md)** — the ElevenLabs `<break>` pause system: which pause
  lengths mean what, how to place them, and two fully annotated reference scripts ("The
  Quiet Marsh," a traveling thread; "Where the Stars Turn," a resting gaze). This is the
  piece that turns a designed investigation into a ready-to-narrate Studio Master.
- **[WORKING_METHOD.md](WORKING_METHOD.md)** — how we collaborate. **Read this first.**
  It defines the bounded design → deliver process and the hard cutoff that prevents the
  endless "let's develop the concept more" loop.

## How to ask for a script

Say something like:

- *"A new script on 'the observation of time'."* (adult investigation)
- *"A new kids' meditation that takes place in the tree canopy."* (children's investigation)

By default you get **a short blueprint + the complete, copy/paste-ready ElevenLabs
script in the same reply.** Say *"just write it"* or *"skip to the end"* to get only the
script. Say *"let's design this one deeply"* to stay in conversation before writing.

The canon evolves by **expansion, not replacement.** New principles get added to the
right volume; existing ones are not rewritten. See WORKING_METHOD.md for how changes
are proposed.
